# À propos

Ce site sert à tester **Eleventy** hébergé sur **GitHub Pages**, avec deux interfaces d'édition :

- **Pages CMS** — via [app.pagescms.org](https://app.pagescms.org)
- **Sveltia CMS** — via la page `/admin/` de ce site

Modifiez ce texte depuis l'un ou l'autre pour voir le résultat après publication.
